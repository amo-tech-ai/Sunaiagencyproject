# Project
Redesign the "Infographics Page" for Sun AI Agency.

The current design is too dark, repetitive, and feels like UI blocks instead of real infographics.

Transform it into a **light, editorial, infographic-driven page** that clearly communicates AI systems visually.

---

# Core Goal

Turn the page into a **visual storytelling experience**, where each section is a **true infographic**, not a card layout.

Focus on:
- clarity
- structure
- visual hierarchy
- flow diagrams
- data storytelling

---

# Key Problems to Fix

1. Too much dark green → reduce heavy backgrounds
2. Sections feel repetitive → add visual variety
3. Infographics look like UI cards → convert to real diagrams
4. Lack of flow → add arrows, connectors, structure
5. Weak hierarchy → improve spacing, contrast, and layout

---

# Color System (IMPORTANT)

Use this layout pattern:

- Hero → dark (deep green)
- Most sections → light (cream / white)
- Alternate sections → soft gray
- CTA → dark

## Colors
- Deep green: #0F2A26 (hero + CTA only)
- Cream: #F7F4EE (main background)
- Light gray: #EEF2F1
- Accent green: #2ECC71
- Text dark: #1A1A1A

70–80% of the page should be LIGHT.

---

# Typography

- Headlines: elegant serif or strong display font
- Body: clean sans-serif
- Increase contrast (avoid faded gray text)
- Clear hierarchy: large titles, readable body

---

# Layout Rules

- Full-width infographic sections
- Use grids, flow layouts, and structured diagrams
- Avoid repetitive card grids
- Add spacing between sections (breathing room)
- Use subtle borders and shadows for depth

# Visual Design Rules

Use:
- arrows
- connectors
- flow lines
- nodes
- charts
- structured layouts

Avoid:
- floating icons with no meaning
- generic UI cards
- overly dark sections
- cluttered visuals

---

# UX Principle

Each section should answer:

"Can the user understand this in 3 seconds without reading?"

If not, simplify.

---

# Final Outcome

The page should feel like:
- a consulting report
- a data visualization system
- a premium AI strategy presentation

NOT a generic SaaS landing page.
