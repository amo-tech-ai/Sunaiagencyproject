# Project
Design a **high-end infographic portfolio page** for Sun AI Agency.

This is NOT a standard SaaS page.

The page must feel like:
- a premium infographic design studio (like Lemonly / Duck Design / Superside)
- a data storytelling platform
- a motion + interactive visual intelligence company

The page should be **graphic-rich, visual-first, and immersive**.

---

# Core Objective

Turn the page into a **visual showcase of infographic samples**.

Each section should:
- BE the infographic (not describe it)
- use diagrams, flows, charts, and structured visuals
- minimize text
- maximize clarity in 3 seconds

---

# Design Style Direction

Inspired by:
- editorial infographic reports
- motion design studios
- interactive infographic platforms (Ceros-style)
- modern data visualization systems

## Style Requirements

- clean, structured, minimal but rich
- strong use of diagrams and flows
- layered compositions (not flat)
- subtle shadows, borders, and depth
- elegant typography
- NO generic SaaS cards
- NO stock photos as main visuals

---

# Color System (Based on Style Guide)

Use a balanced system:

- Deep green: #0F2A26 (hero + CTA only)
- Cream: #F7F4EE (primary background)
- Light gray: #EEF2F1 (alternate sections)
- Accent green: #2ECC71
- Text: #1A1A1A

## Rule:
70–80% LIGHT backgrounds  
Dark only for emphasis

---

# Page Structure

1. Hero (dark)
2. Infographic samples (main content)
3. Services (visual)
4. Process infographic
5. Interactive / motion section
